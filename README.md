# رحلة بين الرؤى والنجوم

موقع تفاعلي لطلاب المرحلة الابتدائية: قصة يوسف عليه السلام، ثم الشمس والقمر والكواكب.

## النشر على GitHub Pages
1. أنشئ مستودعًا جديدًا (Repository) على GitHub.
2. ارفع الملفين: `index.html` و`README.md` إلى الفرع `main`.
3. من Settings ثم Pages: اختر Source = Deploy from a branch، الفرع `main`، المجلد `/ (root)`، ثم Save.
4. بعد دقيقة يظهر الرابط: `https://اسم-المستخدم.github.io/اسم-المستودع/`

## لعبة بستان البذرة
الملف: `index.html` في جذر المستودع، فيفتح على رابط GitHub Pages مباشرة.
أسماء المحطات وكلمات السر في أعلى الكود داخل `CONFIG`.

## متابعة تقدّم الفرق (لوحة المعلّم)
1. أنشئ جدول Google Sheets جديدًا، ثم Extensions ← Apps Script.
2. الصق محتوى `google-apps-script.gs` واحفظ.
3. Deploy ← New deployment ← النوع Web app، Execute as: Me، Who has access: Anyone ← Deploy، ووافق على الصلاحيات.
4. انسخ الرابط الذي ينتهي بـ `/exec` وضعه في `reportUrl` داخل `config.js`.
5. افتح `teacher.html` لترى تقدّم كل فريق (يتحدّث كل ١٠ ثوانٍ)، أو افتح جدول Google نفسه.

أسماء المحطات وكلمات السر أصبحت أيضًا في `config.js`.

## الجولات والنتائج النهائية
- من لوحة المعلّم: «ابدأ الجولة» ثم «أنهِ الجولة». خارج الجولة لا يستطيع اللاعبون السقي.
- «أنهِ اللعبة وأظهر النتائج» يعرض إعادة متحرّكة لتقدّم الفرق جولةً بعد جولة، ثم جدولًا بمرحلة كل فريق بعد كل جولة.
- «لعبة جديدة» يمسح الجدول ويُعيد كل الأجهزة إلى البداية.
- رمز المعلّم هو `TEACHER_PIN` في `google-apps-script.gs` (الافتراضي 1234، غيّره).
- بعد تعديل كود Apps Script: Deploy ← Manage deployments ← تعديل ← Version: New version ← Deploy (الرابط لا يتغيّر).

## الطول والتعزيز
- النبتة تُقاس بالطول (سم/م). السقي الكامل يوصلها إلى ٤ م، والفائز صاحب النبتة الأطول.
- في لوحة المعلّم: اختر المقدار (١٠ سم، ٢٥ سم، ٥٠ سم، ١ م) ثم «تعزيز» أو «تقليل» على بطاقة الفريق. يصل التغيير إلى جهاز الفريق خلال ٥ ثوانٍ.
- بعد ٤ م توجد ٤ مراحل إضافية (٥ م، ٦٫٥ م، ٨ م، ١٠ م) لا يُوصَل إليها بالسقي، بل بتعزيز المعلّم فقط. آخر مرحلة «قمّة البستان» عند ١٠ م.

## هدايا المعلّم والتقليل
- زر «أعطِ» في بطاقة الفريق يرسل هدية (سماد أو غيمة مطر) بالمقدار المختار. تظهر عند الفريق في «هدايا المعلّم»، وعندما يضغطون عليها تظهر حركة السماد أو المطر ثم تنمو النبتة ويظهر مقدار ما نمت.
- زر «تقليل» يُنقص الطول فورًا، ويرى الفريق حركة ذبول وتساقط أوراق مع مقدار النقص.

## محطات الجولتين
- المحطات ١-٤ تُفتح في الجولة الأولى، والمحطتان ٥ و٦ مقفلتان حتى يبدأ المعلّم الجولة الثانية (`round` في `config.js`).
- في المحطتين ٥ و٦ خانة واحدة يكتب فيها المعلّم «فوز» (ماء محطة كاملة) أو «خسر» (٣٥٪ من ماء المحطة). النسب في `results` داخل `config.js`.

## المهام الإضافية
- شريط صغير أعلى يسار الحديقة «مهام إضافية». كل جواب صحيح يملأ الإبريق كاملًا (ماء محطة كاملة).
- الأسئلة وأجوبتها في `sideQuests` داخل `config.js`.
- لوحة المحطات تعرض محطات الجولة الحالية فقط: قبل اللعبة وفي الجولة الأولى تظهر المحطات ١-٤، وعند بدء الجولة الثانية تختفي وتظهر المحطتان ٥ و٦ (محطة الأوراق ومحطة السومو).

## أجزاء الجولة
- الجولة الأولى ٤ أجزاء، والجولة الثانية جزءان، وكل جزء ١٥ دقيقة (`PARTS_PER_ROUND = [4, 2]` و`PART_MINUTES` في `google-apps-script.gs`).
- المعلّم يبدأ كل جزء بنفسه: «ابدأ الجولة» للجزء الأول، ثم «ابدأ الجزء ٢ من ٤»... ويتوقّف السقي تلقائيًا عند انتهاء وقت الجزء، ويظهر للفرق عدّاد تنازلي.
- «أنهِ الجزء» ينهي الجزء الحالي مبكرًا، و«أنهِ الجولة» ينهي الجولة كلها.
- لا يمكن كتابة إجابات المحطات ولا المهام الإضافية إلا أثناء جزء جارٍ: قبل بدء الجولة، وبين الأجزاء، وبعد انتهاء الجولة أو اللعبة تُقفل الخانات مع رسالة توضّح السبب.
